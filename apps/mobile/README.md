# Simple Coffee — Mobile (Flutter) | как запустить новичку

## Что собрано (фронт v0.2)
4 таба + вход:
- **Вход** — телефон → OTP (dev-код подставляется сам) → JWT.
- **Меню** — выбор кофейни, переключатель «В кружке 🍵 / С собой 🥤», каталог с ценами и «+ печать 🦊».
- **Кофейни** — список с выбором точки, бейдж «Завтраки до 14:00».
- **Заказ** — корзина, итог по режиму, создание заказа с idempotencyKey.
- **Печати** — карточка 6 кружек, QR гостя для бариста, заглушка игры «Лис бежит за зёрнами» (Flame в v2.0).

Стек: Flutter + provider + dio + qr_flutter + uuid. Без Riverpod/Flame сейчас — чтобы новичку было проще.

## Запуск (после установки Flutter)
```bash
# 1. убедись что бэк работает:
curl localhost:3000/v1/health
# 2. фронт:
cd /Users/p1umpe/Desktop/coffee-app/apps/mobile
flutter pub get
# iOS-симулятор / Android-эмулятор / Chrome:
flutter run
# важно: для Android-эмулятора поменяй kApiBase в lib/core/api_client.dart на http://10.0.2.2:3000/v1
```

## Сценарий проверки
1. Вход: +79000000000 → код из ответа (подставится).
2. Меню: выбери «В кружке» → добавь 2 капучино → видно «+2 печати».
3. Заказ: «Заказать» → получишь номер А-XX.
4. Печати: покажи QR — бариста сканит через POST /loyalty/stamp (экран КДС добавим позже).
5. Переключи «С собой» → цены упадут на 30₽, печатей нет.
