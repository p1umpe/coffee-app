# Simple Coffee — спецификация дизайна мобильного приложения

Этот файл — контекст для нейросети (Claude, ChatGPT, Cursor и т.п.). Он описывает, как должны выглядеть экраны приложения сети кофеен **Simple Coffee** (Екатеринбург). Референс в коде: `simple-coffee-mockup.html`.

## 1. О проекте

- Мобильное приложение сети кофеен Simple Coffee. Сайт: https://simplecoffee.ru
- Главная идея: **заказ без очереди** и лояльность **«в кружке = печать, с собой = дешевле»**.
- Стек: фронт Flutter (`apps/mobile`), бэкенд NestJS + Prisma/Postgres (`services/api`), интеграция iiko. Задел под мини-игру на Flame.
- Маскот бренда: лисёнок 🦊.

## 2. Общий стиль

Уютная современная кофейня: тёплые натуральные цвета, мягкие скругления, много воздуха, крупные заголовки с засечками, аккуратные карточки. Без резких неоновых цветов и жёстких теней. Настроение: осень, тёплый напиток, домашний уют.

### Цвета (design tokens)

| Токен | HEX | Где используется |
|---|---|---|
| `cream` | `#F7F0E6` | фон экранов |
| `milk` | `#FFFBF5` | карточки, чипы, таб-бар |
| `espresso` | `#2B1D14` | основной текст, тёмная карта лояльности, активные элементы |
| `caramel` | `#C8843B` | второй акцент, аватар, начало градиента баннера |
| `fox` | `#E2622B` | главный акцент: кнопки, печати, активная вкладка, цены-акценты |
| `line` | `#E8DBCB` | границы карточек и разделители |
| `muted` | `#8A7766` | второстепенный текст, подписи |
| `placeholder` | `#EBD9C1` | фон под фото товара |
| `fox-tint` | `#FFF1EA` | фон выбранного размера |
| `ok-text` / `ok-bg` | `#5F7A4F` / `#E6EFDC` | статус «Открыто» |

Градиент баннера: `135deg, #C8843B → #E2622B`.
Тёмная тема на первом этапе не нужна.

### Типографика

- Заголовки экранов и блоков: шрифт с засечками (Georgia в макете; для Flutter — Playfair Display или Lora), размер 21–24, жирность 600–700, межстрочный 1.15.
- Основной текст и цены: гротеск (Manrope; запасной — системный). Размеры: 13–14 названия, 10.5–11.5 подписи, 11 чипы и табы.
- Цены: жирность 800, размер 13–14.

### Скругления, отступы, тени

- Радиусы: карточка лояльности 22, баннер 20, карточка товара 20, карточка кофейни 18, карта 24, фото товара на экране заказа 26, миниатюра товара 16, чипы 14, кнопка CTA 20, переключатель 16 (внутренний сегмент 12), круглые элементы 50%.
- Боковые отступы экрана: 16. Между карточками списка: 8–9. Внутри карточек: 10–16.
- Границы карточек: 1 px `line`.
- Тень допускается только у главной кнопки CTA: `0 8 18 rgba(226,98,43,0.4)`. У остальных карточек тени нет.

### Общие компоненты

**Нижний таб-бар** (на всех экранах, кроме модальных): 4 вкладки — Главная, Меню, Кофейни, Профиль. Фон `milk`, сверху линия `line`. Иконка (17) над подписью (10, жирность 600). Активная вкладка `fox`, остальные `muted`.

**Статус-бар:** системный, время слева, индикаторы справа.

**Чипы категорий:** горизонтальный скролл, высота ~30, скругление 14. Активный: фон `espresso`, текст `cream`. Неактивный: фон `milk`, граница `line`.

**Карточка товара (строка списка):** слева миниатюра 58×58 (фон `placeholder`, радиус 16), в центре название (13, жирный) и описание (10.5, `muted`), справа цена и круглая кнопка «+» 26×26 цвета `fox` с белым плюсом.

## 3. Экраны

### 3.1 Главная

Сверху вниз:
1. **Приветствие:** слева мелкое «Доброе утро» (`muted`, 11) и заголовок «Привет, {имя}!» (serif 21). Справа круглый аватар 34 px цвета `caramel` с лисёнком.
2. **Карта лояльности** (тёмная карточка `espresso`, текст `cream`, радиус 22, padding 16):
   - подпись «Твоя карта» (прозрачность 70%), крупно «5 из 8 печатей» (15, жирный);
   - сетка печатей 4×2: заполненные — круги `fox` с иконкой чашки, пустые — круги с пунктирной границей `cream` 35% прозрачности, последняя — иконка подарка 🎁 (бесплатный напиток);
   - внизу две мини-плашки с полупрозрачным белым фоном: «☕ В кружке — печать» и «🥡 С собой — дешевле».
3. **Промо-баннер:** градиент caramel → fox, радиус 20, слева заголовок serif «Осень уютнее с сезонными чаями» (16, белый) и подпись «Новинки меню», справа крупная иллюстрация чая. По тапу открывает раздел новинок.
4. **Категории:** заголовок «Категории» (14, жирный) и ссылка «Всё меню» справа (`fox`, 12). Ниже 4 плитки в ряд: Кофе, Выпечка, Десерты, Завтраки. Плитка: фон `milk`, граница `line`, радиус 16, эмодзи/иконка 20 и подпись 10.

### 3.2 Меню

1. Заголовок «Меню» (serif 21) и под ним мелко выбранная кофейня («Кофейня на Вайнера, 9»), тап меняет кофейню.
2. Горизонтальные чипы: Кофе (активный), Чай, Выпечка, Десерты (далее по скроллу — Завтраки, Наша кухня).
3. Список карточек товаров: Латте 260 ₽, Флэт уайт 240 ₽, Мокка 290 ₽, Круассан 190 ₽ (цены примерные).
4. Тап по карточке открывает экран заказа. Тап по «+» добавляет в корзину с базовыми параметрами.
5. Внизу над таб-баром, когда корзина не пуста, показывается плавающая кнопка корзины (стиль как CTA).

### 3.3 Заказ напитка (карточка товара)

1. Верхний блок: большое фото напитка в скруглённой области (высота ~150, радиус 26, фон `placeholder`).
2. Название (serif 21), под ним короткое описание (`muted`, 11.5).
3. **Выбор размера:** три равные кнопки S 250 мл, M 350 мл, L 450 мл. Выбранная: граница 1.5 `fox`, текст `fox`, фон `fox-tint`. Остальные: граница `line`.
4. **Переключатель типа заказа** (ключевая механика лояльности): сегмент из двух частей.
   - «В кружке» с подписью «+1 печать»,
   - «С собой» с подписью «дешевле на 10 ₽».
   Выбранная часть: фон `espresso`, текст `cream`. Цена внизу пересчитывается сразу при переключении.
5. Строка опций: молоко, сироп и т.п. (мелкий `muted`).
6. **Кнопка CTA** прижата к низу над таб-баром: фон `fox`, белый текст, радиус 20, слева «Добавить», справа итоговая цена, тень как в разделе 2.

### 3.4 Кофейни

1. Заголовок «Кофейни», подпись «Екатеринбург».
2. Карта (высота ~190, радиус 24, светло-бежевая) с пинами `fox` (капля с белой точкой внутри). Ближайшая кофейня подсвечена.
3. Список кофеен: карточка `milk` с границей `line`, радиус 18: слева адрес (13, жирный) и строка «300 м · до 22:00» (`muted`, 10.5), справа зелёная плашка «Открыто». Закрытые кофейни: серая плашка «Закрыто».
4. Тап по кофейне выбирает её для заказа.

## 4. Состояния и поведение

- Загрузка: скелетоны серо-бежевого цвета на месте карточек, без спиннеров на весь экран.
- Пустая корзина / нет печатей: дружелюбный текст с лисёнком, без ошибок красного цвета.
- Ошибки сети: мягкий баннер вверху в цвете `caramel`, кнопка «Повторить».
- Стоп-лист (товар недоступен): карточка полупрозрачная, вместо «+» надпись «Нет в наличии».
- Анимации: короткие (150–250 мс), плавное заполнение печати при начислении, лёгкий bounce кнопки «+».

## 5. Что ещё предстоит спроектировать

Корзина и оплата, статус заказа («готовится» → «готов»), профиль и история заказов, экран печатей с подробностями, вход по номеру телефона, мини-игра. Новые экраны делать в тех же токенах, радиусах и с тем же таб-баром.

## 6. Шаблон промпта для нейросети

> Ты Flutter-разработчик. Реализуй экран «{название}» мобильного приложения Simple Coffee строго по файлу `simple-coffee-design-spec.md` и визуальному референсу `simple-coffee-mockup.html`. Используй токены цветов и радиусы из раздела 2, вынеси их в `ThemeData` и общий файл `app_tokens.dart`. Шрифты: Playfair Display для заголовков и Manrope для текста. Структуру держи в `apps/mobile/lib/`, данные бери из API по `packages/contracts/openapi.yaml`. Не добавляй тёмную тему и лишние библиотеки. Разбей UI на переиспользуемые виджеты: `StampCard`, `ProductTile`, `CategoryChip`, `OrderTypeSwitch`, `ShopTile`, `AppTabBar`.

## 7. Что в макете условно

Тексты, цены, адреса кофеен, число печатей (8) и скидка за «с собой» (10 ₽) взяты для примера. Фирменные цвета и шрифты с сайта не сверялись с брендбуком: если он есть, замените токены из раздела 2.
