# Simple Coffee — Дизайн в стилистике сайта (v0.1)

Анализ simplecoffee.ru: светлый, воздушный, «простой» бренд. Акцент на фото еды/напитков, дружелюбный тон («Мы любим получать письма!»), легенда о Лисе (маскот), сезонность («Сделайте осень уютнее»), комбо-наборы, завтраки до 12:00/14:00. Текущий сайт перегружен (дубли меню, WooCommerce-корзина в USD) — в приложении делаем чисто.

## 1. Мудборд бренда → токены

**Палитра (тёплый minimal):**
- `--cream: #FAF6F0` — фон (молочная пенка).
- `--coffee-900: #2B211C` — текст (эспрессо).
- `--coffee-600: #6F5B4D` — вторичный текст.
- `--caramel: #C67C3B` — primary CTA (карамель/раф).
- `--fox: #E86A2C` — акцент для new/промо (рыжий лис).
- `--matcha: #7A9B6D` — вег/новинки, статусы «открыто/готово».
- `--line: #EDE6DC` — разделители, карточки `#FFFFFF` с радиусом 16-20.
- Dark mode (v1.1): `#1E1713` фон, кремовый текст.

**Типографика:**
- Заголовки: округлый гротеск — Nunito / Comfortaa (кириллица обязательна!) — дружелюбие.
- Текст/цены: Inter / Manrope — читаемость меню и КБЖУ.
- Шкала: 28/20/16/14/12, межстрочный 130%.

**Форма и тон:**
- Кнопки: крупные (h=52), радиус 14, нижний sticky CTA «Забрать в • через 7 мин — 320 ₽».
- Фото: живые, тёплые, без фильтров; плейсхолдер-лисёнок при загрузке.
- Иллюстрации: лис из «Легенды» — пустые корзины, уровни лояльности, онбординг.
- Тон: «Заберёшь через 7 минут? Мы уже взбиваем молоко 🦊», без официоза.

## 2. Навигация (5 табов)

1. **Меню** (дом): поиск + категории-чипсы (Новинки • Завтраки • Кофе • Десерты • Кухня • Дом), сториз-баннеры, «Повторить прошлое».
2. **Кофейни**: карта + список, бейдж «Завтраки до 14:00» для новых точек.
3. **Заказ** (трекер): статусы с лисьим прогрессом + номер А-12.
4. **Бонусы**: QR, печати/баллы, рефералка, сертификаты.
5. **Профиль**: история, адреса, «Напишите нам», КБЖУ, настройки.

## 3. Ключевые экраны MVP (описание для дизайнера)

- **Онбординг (3 слайда):** 1) «Закажи без очереди» 2) «Копи лисички» (лояльность) 3) «Найди свою кофейню» + ввод телефона.
- **Меню:** сверху — выбор кофейни (адрес + ETA), сториз «Осенние чаи», сетка товаров с фото, бейджи new/хит. Скелетоны при загрузке.
- **Карточка напитка:** фото, конструктор (размер/молоко/сироп/шот — чипы с доплатой +0₽/+60₽), КБЖУ-аккордеон, кнопка «В корзину • 320 ₽».
- **Корзина:** слот «Как можно скорее ~7 мин / Ко времени», промокод, списание бонусов слайдером, чаевые 0/5/10%.
- **Оплата:** СБП (приоритет) / Apple Pay / карта, чекбокс согласия — в стиле сайта (ссылка на согласие ПДн).
- **Трекер:** таймлайн Принят→Готовится→Готов (пульсация), крупный номер, кнопка «Я забрал», оценка 5 звёзд-лисичек.
- **Кофейня:** фото, часы, кнопка «Маршрут (2GIS)», меню этой точки, отзывы.
- **Бонусы:** QR на тёмной карточке + «до бесплатного кофе 2 чашки», уровни Гость/Друг/Легенда с лисом.

## 4. Состояния и детали

- Стоп-лист: карточка гаснет с бейджем «Разобрали 🦊 вернётся завтра».
- Офлайн: баннер «Нет сети — показываем сохранённое меню».
- Ошибки оплаты: «Платёж не прошёл, деньги не списаны. Попробовать СБП?» + альтернатива.
- Пустые: «Пока тут пусто, но капучино уже скучает» + CTA в меню.

## 5. Что взять с сайта, что исправить

- Взять: категории, комбо-подход («Напиток + рап/киш/сэндвич — идеально!»), сезонность, блок «Напишите нам» (4 адреса → 1 форма с темой), КБЖУ (из PDF → в цифру), сертификаты/зерно/дрипы как витрина.
- Исправить: дубли меню, USD-корзину, тяжёлые фото, отсутствие поиска/фильтров, мелкий текст.

## 6. UI-кит для старта (Flutter)

- Токены в `app_theme.dart`: цвета, радиусы, тени (мягкая `0 8 24 rgba(43,33,28,.08)`).
- Компоненты: `SCButton`, `SCCard`, `SCChip`, `SCBottomSheet` (конструктор), `SCStory`, `SCOrderTimeline`, `SCBonusCard`.
- Иконки: линейные, скруглённые (Lucide-стиль), фото 4:3.
- Прототип: Figma — 1 файл: Cover (мудборд с сайта) → Wireframes → UI → Prototype «30-секундный заказ».
