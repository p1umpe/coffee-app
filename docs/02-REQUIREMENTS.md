# Simple Coffee — Функциональные и нефункциональные требования (v0.1)

## 1. Функциональные требования (FR)

### FR-1. Каталог и меню
- FR-1.1 Категории как на сайте: Новинки, Завтраки до 12:00, Кофе и напитки (Эспрессо/Капучино/Латте/Раф/Черный кофе/Чай/Матча/Смузи/Холодные/Какао), Десерты (Торты/Малые/Сырники), Выпечка, Кухня (Рапы/Сэндвичи), Для дома (Зерно/Капсулы/Дрипы), Комбо, Мерч, Сертификаты.
- FR-1.2 Карточка: фото, описание, цена по точке, модификаторы (размер, молоко, сиропы, шоты), КБЖУ/состав, теги new/хит/вег.
- FR-1.3 Мультименю: база сети + переопределение точкой, стоп-лист в реальном времени.
- FR-1.4 Поиск, фильтры (без кофеина, до 200 ккал), «повторить прошлый», офлайн-кэш меню.

### FR-2. Кофейни и гео
- FR-2.1 Список + карта (2GIS SDK): расстояние, статус открыто/закрыто, загруженность, телефон.
- FR-2.2 «Ближайшая кофейня», любимая точка, карточка: часы, флаг «Завтраки до 14:00», маршрут.

### FR-3. Заказ и оплата (Самовывоз MVP)
- FR-3.1 Корзина: модификаторы, промокод, списание бонусов, чаевые.
- FR-3.2 Слот: ASAP (7/10/15 мин) или ко времени. Режимы: DINE_IN (в кружке, в зале, базовая цена) / TAKEAWAY (с собой, дешевле на X₽). Доставки НЕТ — только самовывоз (включая QR-заказ за столом).
- FR-3.3 Оплата: СБП, Apple/Google Pay, карта (CloudPayments/ЮKassa). Только токены провайдера.
- FR-3.4 Статусы live: Принят-Оплачен-Готовится-Готов-Выдан. Push + трекер + номер А-12.
- FR-3.5 Отмена до старта готовки = автовозврат.


### FR-4. Лояльность
- FR-4.1 Вход по телефону (OTP), согласие на ПДн, удаление аккаунта в 1 клик.
- FR-4.2 Механика «Кружка=печать»: DINE_IN = +1 печать за каждый кофе (подтверждает бариста сканом при выдаче в кружке), 6 печатей = 7-й кофе бесплатно (купон, TTL 30 дней). TAKEAWAY = скидка −X₽, без печатей. Еда/зерно печатей не дают.
- FR-4.3 QR гостя для кассы, рефералка, сертификаты (покупка/подарок/оплата кодом).
- FR-4.4 История, чеки ФЗ-54, оценка заказа.

### FR-5. Коммуникация
- FR-5.1 Push (FCM/APNs): транзакционные + маркетинговые с deeplink. Настройки подписок.
- FR-5.2 Баннеры/сториз («Сезонные чаи», «-20% на еду»), «Напишите нам» (похвалить/пожаловаться в 1 форму с темой).

### FR-6. Админка сети (Backoffice)
- FR-6.1 Роли: владелец/менеджер/бариста/поддержка/маркетолог.
- FR-6.2 Меню и цены по точкам, стоп-лист за 10 сек, расписание завтраков.
- FR-6.3 КДС-лента заказов, возвраты, промо-конструктор (комбо, скидки по времени, промокоды).
- FR-6.4 Аналитика: заказы/точка/час, средний чек, retention, воронка.

### FR-7. Интеграции
- POS iiko/R-Keeper (меню, заказы, стоп-лист, фискализация), 2GIS, платежи, SMS, ОФД, AppMetrica, feature-flags.

## 2. Нефункциональные требования (NFR)

- NFR-1 Надежность: uptime 99.9%->99.95%, RTO<15мин RPO<5мин, идемпотентность заказов (Idempotency-Key), outbox+ретраи+DLQ, офлайн-режим КДС, crash-free>99.5%.
- NFR-2 Масштабируемость: расчет 20 кофеен*300 чеков=6000/день, пик 30/мин, запас x10 = 300 rps write / 1500 rps read. Stateless API+LB, Redis (hit>90%)+CDN, PG primary+replica, партиции заказов, очереди для пиков, k8s-автоскейл, k6-тесты на 5x пик.
- NFR-3 Скорость: p95 каталог API<200ms, создание заказа<600ms, открытие каталога<800ms на 4G, старт приложения<2с, вес<35MB, WebP через CDN.
- NFR-4 Безопасность: OWASP MASVS, TLS+pinning, Keychain/Keystore, JWT 15мин+refresh rotation, rate-limit OTP, ПДн 152-ФЗ (РФ), PCI scope-reduced, SAST/DAST, pentest перед prod.
- NFR-5 Совместимость: iOS 15+, Android 8+, RU, доступность WCAG AA, темная тема v1.1.
- NFR-6 Наблюдаемость: SLO-дашборды, Prometheus/Grafana/Loki/OTel/Sentry, алерты (просадка заказов>2% за 5мин), CI/CD с canary и rollback<5мин, тесты домена заказов>70%.

## 3. Definition of Done MVP

1. Путь установка->первый предзаказ->push Готово->QR <3 мин.
2. 100 заказов без потерь при обрыве сети в кофейне.
3. Нагрузка 300/50 rps: p95 в норме, ошибок<0.1%.
4. Оплата СБП+возврат+чек ОФД проходят.
5. Стоп-лист скрывает позицию за секунды.
