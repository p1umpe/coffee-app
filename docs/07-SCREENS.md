# Simple Coffee — карта экранов: что есть и что нужно (v0.3)

Основа: `docs/design/simple-coffee-design-spec.md` + макет.
Механика: в кружке = печать, с собой = дешевле. Печатей до бесплатного: 6 (бэк).
Таб-бар: Главная / Меню / Кофейни / Профиль. Корзина — CTA + отдельный экран.

## 1. Что уже есть (7 экранов)

| Экран | Файл | Статус |
|---|---|---|
| Вход по телефону (OTP) | `auth_screen.dart` | готов |
| Главная | `home_screen.dart` | готова: приветствие, StampCard, баннер, категории |
| Меню | `menu_screen.dart` | готово: чипы, ProductTile, CTA корзины |
| Заказ напитка | `product_screen.dart` | готов: размер, OrderTypeSwitch, CTA |
| Кофейни | `shops_screen.dart` | готовы: карта-заглушка, ShopTile |
| Корзина | `cart_screen.dart` | готова: список, тип, заказ |
| Профиль | `profile_screen.dart` | базовый: StampCard, QR, игра-заглушка |

## 2. Не хватает — критично для MVP (без них не запуститься)

| # | Экран | Зачем |
|---|---|---|
| 1 | Оплата (`checkout_screen.dart`) | СБП / Apple Pay / карта / купон, итог, «Оплатить». Сейчас заказ висит в PENDING_PAYMENT |
| 2 | Статус заказа (`order_status_screen.dart`) | Трекер Принят-Готовится-Готов-Выдан + номер А-12 + «Я забрал» |
| 3 | Успех/неудача оплаты (состояния checkout) | «Оплачено, готовим!» vs «Не прошло, попробуй СБП» |
| 4 | История заказов (`orders_history_screen.dart`) | Список + «Повторить как в прошлый раз» — драйвер возврата |
| 5 | Детали кофейни (`shop_details_screen.dart`) | Часы, телефон, маршрут 2GIS, меню точки, «Заказать сюда» |
| 6 | Мои купоны (вкладка Профиля) | Бесплатный 7-й кофе: QR + срок 30 дней. Сейчас купон невидим |

## 3. Не хватает — важно после MVP (2-4 недели)

| # | Экран | Зачем |
|---|---|---|
| 7 | Онбординг (3 слайда) | «Без очереди» → «Копи лисички» → «Своя кофейня» + телефон |
| 8 | Оценка заказа (bottom-sheet) | 5 звёзд-лисичек + комментарий → NPS |
| 9 | Напишите нам (`feedback_screen.dart`) | Похвалить/пожаловаться/аренда с фото. На сайте 4 email — в 1 форму |
| 10 | КБЖУ и состав (аккордеон в товаре) | Сейчас только PDF на сайте |
| 11 | Настройки (в Профиле) | Push-подписки, любимая кофейня, удаление аккаунта (требует App Store) |
| 12 | Экран бариста / КДС-лайт (`barista_screen.dart`) | Лента заказов + «Готовится/Готов/Выдано в кружке + скан». Без него печати некому начислять! |
