# Simple Coffee — User Flow (v0.3)

Продолжение `07-SCREENS.md`. Буквы путей: A — первый запуск, B — заказ в кружке
(ядро 30 сек), C — с собой, D — бесплатный кофе, E — смена кофейни, F — оплата,
G — бариста, H — feedback, I — офлайн/стоп-лист.

## FLOW A. Первый запуск (новый гость)

Splash с лисом → Онбординг-1 «Закажи без очереди»
→ Онбординг-2 «Копи лисички» → Онбординг-3 «Найди свою кофейню»
→ Вход: телефон → SMS-код → JWT + guestQr
→ Выбор кофейни (ближайшая подсвечена)
→ Главная: «Привет, Гость! · 0 из 6 печатей».

## FLOW B. Быстрый заказ в кружке (ядро)

Главная → баннер/«Повторить» или Меню → чип «Кофе»
→ Заказ напитка: размер M → «В кружке +1 печать»
→ CTA «Добавить — 260 ₽» → тост «Добавлен»
→ CTA корзины → Корзина → Оплата (СБП)
→ Успех: «Заказ А-12 · ~7 мин»
→ Статус: Принят → Готовится (push) → Готов (push «Забирай!»)
→ В кофейне: QR из Профиля → бариста «Выдано в кружке» + скан
→ +печати с анимацией → Оценка 5 лисичек → Главная «1 из 6».

## FLOW C. С собой дешевле

Меню → Заказ напитка → «С собой — дешевле»: цена падает сразу
(260 → 250 ₽), подпись «без печатей»
→ Корзина → Оплата → Статус → забрал со стойки без QR
→ Нудж в Профиле: «В следующий раз пей в кружке — до бесплатного N».

## FLOW D. Бесплатный 7-й кофе

Пуш «Ура! Бесплатный кофе (30 дней)» → Мои купоны → QR купона
→ Меню → любой кофе → Корзина → применить купон → итог 0 ₽
→ Статус → бариста сканирует купон → Выдано
→ счётчик обнуляется → «0 из 6, копим заново».

## FLOW E. Смена кофейни / закрытая точка

Меню «Кофейня на Вайнера, 9» (тап) → Кофейни
→ «Малышева, 51 · Закрыто» (серая плашка): алерт
«Откроется в 9:00. Выбрать Вайнера?»
→ выбор открытой → меню и цены пересчитались, корзина очищена
(предупредить: «Корзина очистится — другая кухня»).

## FLOW F. Ошибка оплаты / возврат

«Платёж не прошёл, деньги не списаны»
→ [Попробовать СБП] / [Другая карта] / [Оплатить в кофейне]
→ успех → FLOW B; отмена до «Готовится» → автовозврат + пуш «Вернули ₽»
→ после «Готовится» → только через бариста («Позвать помощь»).

## FLOW G. Путь бариста (КДС-лайт)

Вход по PIN → Лента заказов точки → новый подсвечен + звук
→ Карточка А-12: состав, «в кружке», имя
→ [Принят] → [Готовится] → [Готов] (гостю push)
→ гость показывает QR → [Скан] → «Выдано в кружке · +N печатей».

## FLOW H. Обратная связь

Профиль → «Напишите нам» → тема (Похвалить/Пожаловаться/Аренда)
→ текст + фото чека → «Ответим за день».

## FLOW I. Нет сети / стоп-лист

Нет сети: caramel-баннер «Показываем сохранённое» + Повторить;
заказ — в очередь, уйдёт сам.
Стоп-лист: карточка полупрозрачная, вместо «+» — «Нет в наличии».

## Порядок сборки

1. Итерация 1 (P0): Оплата + Статус + История (FLOW B замыкается).
2. Итерация 2 (P1): Купоны + Детали кофейни + Онбординг (FLOW A, D).
3. Итерация 3: Оценка + Напишите нам + КБЖУ + Настройки + КДС-лайт.
